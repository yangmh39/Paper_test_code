# 基于两阶段蒙特卡洛模拟的产线布局鲁棒性后评估

针对单工厂异构布局（U 型 / 直线 / 环型 / 并行）人机协同选择性拆解 MILP 模型，用两阶段蒙特卡洛模拟做鲁棒性后评估：Stage 1 求解确定性最优方案，Stage 2 在工时 / 疲劳 / 工位故障三重扰动下评估可行率与利润稳定性，对比四种布局的鲁棒性水平。

## 文件说明

| 文件 | 说明 |
|---|---|
| `experiment.py` | 两阶段蒙特卡洛实验主脚本（含收敛判据） |
| `plot_results.py` | 生成 4 张论文用图 |
| `实验设计.md` | 完整实验设计（假设、因子、扰动分布、指标、统计方法） |
| `问题描述.md` | 拆解系统 MILP 数学模型（上游输入） |
| `cleaned_data.csv` | 产品实例库（968 款手机规格，实验取 60 款分层抽样） |
| `results.csv` | 实验结果（4 布局 × 4 方法 × 5 扰动场景，含收敛样本数 n_used） |
| `fig1~fig4.png` | 鲁棒性指标 / 敏感度热力图 / 方法权衡 / 利润分布 |

## 环境依赖

Python 3.12，`numpy`、`pandas`、`scipy`、`matplotlib`。

## 复现命令

```bash
# 1. 跑实验（约 20s，固定随机种子可复现）
python -I experiment.py --products 60 --sims 4000 --seed 0 --out results.csv

# 2. 生成数据图
python -I plot_results.py
```

## 方法要点

- **两阶段分离**：上层设计变量（布局选择 / 产线工位开启 / 操作员分配）固定 MILP 解不变；下层对扰动随机采样重评估。
- **扰动模型**（与方法.pdf §3.2 一致）：工时 `Normal(t,(σ_t·t)²)`、疲劳 `Normal(ε,(σ_ε·ε)²)`、工位故障 `Bernoulli(p_f)`（故障则该工位全部任务失效，前驱级联丢失）。
- **收敛判据**：N 从 800 起每 200 增加，连续两组 E[f₁]/R_feas 相对偏差 <1% 收敛（上限 4000）。
- **对照方法**：后评估法 / 鲁棒优化 RO（工时×1.5 最坏情形）/ 随机规划 SP（均值+1σ 安全边际）/ 基础蒙特卡洛。

## 注意事项

- Stage 1 用价值/工时贪心列表调度作为 MILP **代理**，接口处可替换为 PuLP / Gurobi。
- `LAYOUTS` 中的布局特征参数（工位数、疲劳乘子、姿态灵活性）为**假设值**，需在论文中给出依据或做敏感性扫描。
